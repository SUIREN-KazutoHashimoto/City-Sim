# City Generator v2 Phase 4.14 — 右側通行・直線型鉄道ネットワーク

## 目的

複線区間で上下列車が同じ側の線路を使うことによる閉塞競合・デッドロックを減らし、鉄道ネットワークを「1路線を道路に沿って曲げ続ける」構成から「直線的な複数路線を乗り換えて使う」構成へ移行する。

## 右側通行

幹線複線は進行方向に対して右側通行を標準とする。

RailRendererのpath正方向では正のoffsetが左側になるため、正規線は以下で決定する。

```text
進行方向 +1 -> lane -1
進行方向 -1 -> lane +1
```

初期配置、終端折返し、車両基地出庫、進路選択、閉塞信号、分岐表示を同じ規則で統一する。

## 反対線使用

渡線による反対線運転は通常経路ではない。

- 特急: 12秒以上待ちで検討
- 快速: 30秒以上待ちで検討
- 普通: 75秒以上待ちで検討
- デッドロック復旧対象列車: 即時検討可能

反対線へ入る場合、その駅間の3閉塞すべてが空いていることを要求する。

さらに、反対線運転中の編成が存在する駅間には、その線を正規方向に使う対向列車を新たに進入させない。

これにより渡線使用による向かい合わせ停止を抑制する。

## 線路生成

従来は駅間を道路A*経路へ寄せていたため、道路形状に合わせた細かなカーブが大量に発生していた。

Phase 4.14では、道路Nodeは駅アクセス・バス接続用としてのみ保持し、高架線路は計画時の駅座標を直接結ぶ。

- 幹線: 原則直線
- 支線: 駅間を直接接続
- 終端: 土地側ターミナルへの最終アプローチのみ曲線を許容
- 微小な道路曲線への追従は行わない

これにより曲線速度制限が頻発する状態も減らす。

## 路線数

標準都市設定の幹線数を2路線から3路線へ増やす。

各幹線はCBDを異なる角度で横断する直線軸を持つ。中央駅では各幹線相互の乗換が可能で、副都心支線の接続駅も乗換駅として扱う。

```text
幹線1  ─────────╲
                  ╲
幹線2  ───────── 中央駅 ─────────
                  ╱
幹線3  ─────────╱
```

1路線を大きく蛇行させて各需要点を拾うのではなく、複数の直線路線と乗換で都市をカバーする。
