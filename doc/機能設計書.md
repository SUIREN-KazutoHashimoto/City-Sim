# 設定・起動

## 3. F-01 都市設定読込・Seed解決

### 入力

`public/config/city.json`

### 処理

- JSON取得
- default merge
- 値域検証
- `seed="random"` 解決
- `areaKm2` から正方形都市一辺を算出

### 出力

`CityConfig` / `CityPlanningOptions`

### 注意

設定値とruntime実効値を区別する。例:

- `railStationSpacing=525` は固定駅間ではなく基準値
- `parkRatio=0.055` は最終公園率ではない

---

## 4. F-02 シミュレーション時間

SimulationClockがreal timeとsim timeを分離する。

Loading中は通常simulationをPreRollし、visible start直後の初期burstを消化する。

高倍率時:

- simulation batch
- backlogに応じたrender cadence調整
- Railは独自frame budget

# 都市生成

## 5. F-03～F-06 都市計画・道路・建物・公園

### 都市計画

CBD/SubCenter、用途District、urbanScore、landValue、density、transit influenceを生成する。

### 道路

Road hierarchy:

```text
Highway > Arterial > Collector > Local > Path
```

Arterial/Collectorはdensity/districtにより複数車線化する。

Local道路は低密度・工業/物流地区ほど一部省略する。

### Block/Parcel

道路で囲まれたBlockをParcelへ分割し、frontage/depth/setback/consolidation/development intensity/coverage/FARから建物を生成する。

### 公園

初期Park生成後、最終高さ帯別quotaで余剰を削減する。

- high/super-high: 約2%
- mid: 約1%
- low: 約5%

不足を補充する機能ではない。

### 森林

rural/vacant lotへ生成。農地転用範囲は除去する。

---

## 6. F-07 農場/郊外産業

### 入力

- 生成済み都市
- road network
- rural candidate positions
- legacy production sites

### 処理

Farmをmulti-block estateへ変換する。

```text
field
+ office
+ warehouse
```

Farm interiorを横切る一般道路を抑止する。

Final refinementで、道路/他建物/他farmと衝突しない場合はfieldを追加拡張する。

### 出力

Farm production site:

- warehouse logistics position
- field extent
- office/warehouse Work POI
- field area
- block scale

### 制約

Truck sourceはwarehouse側。field centerをlogistics sourceにしない。

---

## 7. F-08 Fleet depot

Taxi/Bus/Freight depotを各1拠点生成する。

各depot:

- building
- roadNode
- private parking lot
- fleet slots

を持つ。

Private parking POIは一般resident carへ公開しない。

# 市民・道路交通

## 8. F-09 市民/Utility AI

市民はSoA AgentStoreへ保持する。

Utility AIが勤務、食事、買物、娯楽、帰宅等を評価し、POI容量・在庫・属性を考慮して行動を決める。

POI予約の最終確定はCoordinator側。

---

## 9. F-10 徒歩/横断歩道

SidewalkNetwork A* routeを使用する。

### Crossing safety

横断中のpedestrian occupancyを保持し、進入vehicleへblockする。

### 赤信号待機

歩行者信号が赤でもrouteを変更/破棄しない。

- crossing entry約1.15 m手前まで接近
- velocity 0で待機
- signal green + vehicle conflict解消後に継続

---

## 10. F-11/F-12 道路車両・多車線

### 基本走行

RoadNetwork A* + TrafficSystem Edge progression。

TrafficSystem:

- signal
- pedestrian block
- IDM following
- occupancy
- arrival

を管理する。

### Lane

MultiLaneTrafficTuningがcurrent lane / target lane / lane changes / turn laneを管理する。

### Turn lane convergence

TurningLaneTransitionFixは、turn laneとdownstream lane reductionの矛盾を解消する。

実RoadEdge.lanesは変更しない。

### Turn visual path

TurningVisualPathTuningは交差点内の表示poseだけを補正する。

- car: 15 m
- truck: 21 m
- bus: 25 m

の出口側区間でincoming lane centerからoutgoing lane centerへ曲線接続する。

# バス・タクシー・物流

## 11. F-13 バス

### Base stop generation

Base BusSystemが3本×2軸のgrid line候補とstopを作る。

### Short route rebuild

ShortBusRouteTuning:

- 元lineを最低4分割
- Road A*で実距離測定
- route循環総延長 <= 5,000 m
- target 約4,600 m
- shared boundary stopを許容

### Fleet

- >=3.2 km またはstop sequence多め: 4台
- その他: 3台

### Station feeder

Central/SubCenter feederも5 km以下へ短縮。

### 出力

Short local bus network + bus depot based vehicle operation。

---

## 12. F-14 タクシー

### Fleet

Target:

```text
round(population / 800)
```

を18～120台へclamp。

### Choice

350 m以上のtripが対象。

住民:

- wealth
- night
- distance
- fallback状況

Visitor:

- hotel
- tourism
- その他purpose

等から確率を決める。

### Runtime

```text
idle
→ to-pickup
→ boarding
→ occupied
→ alighting
```

boarding/alighting各4秒。

### 出力

Taxi passenger snapshot、vehicle phase、Dashboard/Inspector向け情報。

---

## 13. F-15 産業物流

Production chain:

```text
farm/raw-factory
→ processor
→ assembler
→ retail/food or export
```

Truck:

- fleet 18～72
- capacity 240
- source travel
- 5秒loading
- destination travel
- 6秒unloading
- freight depot return

Final productsはRetail/Food stock補充またはgate exportへ送る。

---

## 14. F-16 職場人数/生産効率

### 人数

- present = 出勤
- assigned = 在籍
- capacity = 定員

### Production efficiency

```text
efficiency = present / capacity
```

Physical production siteのactual process rateへ適用する。

### Farm

Farm base rateはfield areaで決定する。

```text
base = max(6, fieldArea / 7000)
actual = base × efficiency
```

### Inspector

Workplace type + 出勤 / 在籍 / 定員 / 生産効率または稼働効率を表示する。

# 鉄道

## 15. F-17 鉄道路線計画

### 入力

- CBD/SubCenter context
- planning options
- RoadNetwork

### 処理

- 幹線（標準3路線）
- 副都心支線
- station roadNode
- Road A* running path
- rural station spacing

### 駅間隔

Configured 525 mはbase。

Locality factor:

```text
core 1.0
→ outskirts
outer edge 2.0
```

### 制約

Station metadata位置とrunning lineを同一視しない。

---

## 16. F-18 駅周辺clearance

### Physical rail clearance

線路/駅設備包絡へ干渉するbuilding/parkingを除去。

### Final no-building clearance

全建物生成後:

- Central/SubCenter: 78 m
- Local/Terminal: 56 m

+ building half diagonalで再検査。

Production/facility/depot等も対象。

---

## 17. F-19～F-24 在来鉄道

### Track/station

Visible station geometryはfinal smoothed railへ追従。

### Operations

- Local / Rapid / Limited
- right-hand operation
- block/signal
- passing loops
- turnout/siding
- terminal/depot
- deadhead
- 15-second timetable quantum

### Passenger

Street → station access → platform → actual train → platform → street。

最大1回transfer。

### Station equipment

- benches
- vending machines
- fluorescent/emissive lights
- real lights
- ceiling departure board
- stairs/access
