# City Generator v2 Phase 4.5 — 鉄道運行・追跡・待避線

Phase 4で追加した鉄道を、単なる都市形成・表示レイヤーから最低限の運行システムへ拡張する。

## 実装範囲

- 全駅停車
- 駅手前での減速 / 発車時の加速
- 駅種別の停車時間
- 道路A*由来の直角折れをquadratic filletで丸めた線路
- 曲線に沿った列車heading
- 幹線駅の待避線
- 駅間1閉塞の簡易閉塞制御
- 対向列車の駅交換
- 同方向後続列車の駅待機
- 列車Inspector
- 中クリックによる列車三人称追跡
- 曲線追従型の駅ホーム / 待避線形状
- 路線単位の待避線可否判定

## 停車時間

- 中央駅: 24秒
- 副都心駅: 20秒
- 一般駅: 14秒
- 終端駅: 22秒

列車は等速で駅を通過せず、残距離から制動可能速度を計算する。

```text
cruise
   ↓
station approach
   ↓
deceleration
   ↓
0 km/h
   ↓
dwell
   ↓
acceleration
```

## 曲線

RailPlanningのA*経路自体は道路網に沿うpolylineのまま維持する。
Renderer側で角をquadratic Bezierの短いfilletへ置き換える。

駅ノードがA*上の曲がり角に一致している場合も直角をそのまま残さず、駅停止位置は丸めた線形へ投影する。
カーブ半径は道路交差点付近から大きく逸脱しないよう最大約22mに抑える。

列車headingは単一segment角度ではなく、走行位置の前後をサンプリングして計算するため、カーブで向きが段階的に跳ねにくい。

## 駅ホーム

ホームを線路中心へ置かない。
列車幅と安全余裕を考慮して、走行線の外側へ配置する。

単線区間:

```text
──────── platform

══════ running track ══════
```

待避線駅:

```text
platform ─────────────
      ═══ 上り待避線 ═══
          ═ 本線 ═
      ═══ 下り待避線 ═══
───────────── platform
```

ホームは長い1枚のBoxではなく、約8m単位の短いsegmentに分割して実線路の曲率へ追従させる。
屋根も同じ線形に追従する。

列車外縁とホーム端の間には約0.42mの安全余裕を確保する。

## 待避線

幹線(trunk)の終端以外の駅にはpassing loopを追加する。

待避線を駅接線方向へ単純な直線として生成せず、本線のsmoothed pathをサンプリングし、その法線方向へ側線を生成する。

分岐部では約24mのapproach区間を使い、smoothstepで

```text
本線中心 → 側線中心 → 本線中心
```

と変位する。

列車の横方向変位にも同じprofileを使うため、描画されたレールと列車走行位置が一致する。

支線は現時点で1編成を基本とするため、標準では待避線を要求しない。

## 閉塞

同一路線の隣接駅間を1閉塞として扱う。

列車が駅を発車するとき、次駅までの閉塞に別列車が存在する場合は発車しない。

状態:

- `dwell`: 駅停車
- `running`: 閉塞内走行
- `signal`: 次閉塞空き待ち

待避線駅では逆方向列車2本まで駅に同時進入できる。
同方向列車は同一駅へ重ねず、後続側を閉塞待ちにする。

待避線判定は駅全体ではなく、現在走行している路線に実際にpassing loopが存在するかで判定する。
これにより、同じ駅へ幹線と支線が乗り入れる場合に支線側を誤って待避可能と判断しない。

## Inspector / 追跡

Train InstancedMeshをRaycaster対象へ追加する。

表示内容:

- 列車ID
- 路線名
- 走行 / 停車 / 閉塞待ち
- 現在速度 / 上限速度
- 現在駅 / 次駅
- 上り / 下り
- 待避線有無

中クリックで列車を追跡できる。
列車追跡はheading相対の三人称orbitを使用する。
`V`固定一人称は従来どおり自動車・バスのみを対象とする。
