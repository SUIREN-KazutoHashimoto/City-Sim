# City Generator v2 Phase 4.6 — 鉄道車両・快速・信号・駅アクセス

Phase 4.5の簡易鉄道運行を、複数車両の編成・台車追従・快速運転・鉄道信号・高倍率描画補間を持つ都市鉄道へ拡張する。

## 実装範囲

- SIM時間と描画位置の分離
- 高い時間倍率でも列車の描画位置を実時間補間
- 10m級の短車体を3〜5両連結
- 各車両の前後台車点による姿勢決定
- 各停 / 快速
- 各停は待避線、快速は本線を使用
- 同方向の快速追越し
- 鉄道専用信号機
- 赤 / 黄 / 緑の現示
- 人 / 車 / バス / トラック / 列車すべてでVによる一人称 / 三人称切替
- 最終駅位置周辺の建物・駐車場クリアランス
- 高架ホームから地上へ降りる階段
- POI WorkerへcapacityをSharedArrayBufferで共有し、駅クリアランスによるPOI無効化を即時反映

## 描画補間

鉄道運行状態は`simSeconds`まで追いつかせるが、描画には`visualDistance`を使用する。

```text
SIM distance ────────┐
                     │ target
                     v
visualDistance ── smooth follow ──> renderer / camera / inspector
```

非同期SIM batchや高い時間倍率で運行距離が大きく進んでも、1フレームで列車Meshをテレポートさせない。

## 車両編成 / 台車追従

従来の25m箱1個を廃止する。

標準:

- 支線各停: 3両
- 幹線各停: 4両
- 幹線快速: 5両
- 1両: 約10.2m
- 連結間隔: 約0.72m

各車両は車体中心の接線角度ではなく、前後2点を線路上から取得する。

```text
rear bogie  o==========o  front bogie
              car
```

車体位置:

```text
(front + rear) / 2
```

車体heading:

```text
atan2(front.z - rear.z, front.x - rear.x)
```

これによりカーブでは各車両が独立して線路形状へ追随する。

## 各停 / 快速

幹線では各停に加えて快速を生成する。

### 各停

- 全駅停車
- 待避設備のある駅では進行方向側の待避線へ入る
- 幹線最高速度 約77km/h

### 快速

- 中央駅
- 副都心駅
- 終端駅
- 一部一般駅

に停車し、それ以外は通過する。

- 本線を使用
- 最高速度 約97km/h
- 待避駅で停車中の各停を追い越せる

支線は現時点では各停のみ。

## 待避駅

本線と待避線の中心間隔を約8mへ広げ、その間に島式ホームを配置する。

```text
local siding  ========
             [platform]
rapid main    ========

rapid main    ========
             [platform]
local siding  ========
```

快速は本線、各停は待避線という役割を固定するため、待避線が運行上の意味を持つ。

## 鉄道信号

各駅の出発側に鉄道専用信号を配置する。

現示:

- 緑: 次閉塞・次駅が空き
- 黄: 次駅に列車あり
- 赤: 次閉塞に列車あり

運行制御自体も駅間1閉塞を基本とする。

## 駅クリアランス

鉄道駅は道路網完成後に最終位置へスナップされるため、CityGeneratorの初期建物配置だけでは駅構内と建物が重なる可能性がある。

`reserveRailStationClearance()`を人口生成前に実行し、最終駅位置周辺の建物・駐車場を除外する。

除外した建物のPOIはIDを維持したままcapacity=0へ変更し、残存Building ID / Facility IDを再構成する。

## POI Worker整合

POI検索WorkerはWorld生成時に作られるため、駅クリアランスはその後になる。

そのため`capacity`も`occupancy`と同様にSharedArrayBufferへ変更した。

駅クリアランスでPOIを無効化するとWorker側の検索候補からも即時に外れる。

## 駅階段

各ホームの両端から、線路を横切らないよう線路方向へ階段を下ろす。

現段階では軽量なBox集合による階段形状で、エレベーター・エスカレーター・改札は今後の拡張対象。

## 追跡カメラ

`V`は車両専用キーから、現在追跡中の対象の一人称/三人称切替へ変更した。

対象:

- 市民: 目線高さ
- 乗用車: 運転席相当
- バス: 運転席相当
- トラック: 運転席相当
- 列車: 先頭車運転台相当

列車追跡は編成中心ではなく先頭車poseを使用する。

## 現時点の境界

- Agentはまだ列車に乗車しない
- ダイヤグラム/時刻表は未実装
- 信号は3現示相当の簡易閉塞信号
- 路線間で共有する線路区間の連動閉塞は未実装
- 階段に歩行者用Networkはまだ接続していない
- 車両は短車体の都市鉄道表現で、厳密なモノレール軌道構造ではない

次段ではAgentの徒歩→駅→列車→乗換→徒歩/バスを含むマルチモーダル経路探索へ接続する。
