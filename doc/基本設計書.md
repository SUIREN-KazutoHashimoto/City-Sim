## 2. システム概要

City-Sim は TypeScript / three.js によるブラウザ向けリアルタイム都市シミュレーションである。

市民、道路、歩道、自家用車、路線バス、配送トラック、信号、建物、POI、店舗在庫を相互作用させ、都市活動を時間経過に沿って発生させる。

主な実装機能:

- ノイズベースの手続き型都市生成
- 建物用途と建築アーキタイプを分離した建物生成
- 市民の職業・勤務時間・欲求・資産・性格・自宅・職場
- Utility AI による行動選択
- 徒歩 / 自家用車 / 路線バスによる複合移動
- 道路グラフ / 歩道グラフの分離
- A* 経路探索
- IDM 相当の車両追従
- 通常信号 / スクランブル信号
- 駐車場 / 物理駐車スロット
- Food / Retail の在庫と物流補充
- GPU Instancing を維持した複合形状レンダリング
- 市民 / 車両 / 建物 Inspector
- シミュレーション速度変更 / 24時間活動グラフ
- 時刻に連動した昼夜ライティング

## 5. アーキテクチャ

### 5.1 OOP + データ指向

大量エージェントの実データは SoA（Structure of Arrays）形式で保持する。

```text
AgentStore
  posX[] / posZ[]
  energy[] / hunger[] / ...
  state[]

VehicleStore
  posX[] / posZ[]
  speed[] / accel[]
  edge[] / segT[]
  state[]
```

`GameObject` / `Pedestrian` 等はドメイン表現用の薄いファサードとする。

### 5.2 System / Store / World

- Store: 状態保持
- System: Storeを走査して状態更新
- World: System間の配線、順序、複合状態遷移
- Rendering: Store / World を読み取り表示へ同期

### 5.3 描画互換レイヤ

レンダリング拡張後も既存の `InstancedRenderer` を基底として維持する。

```text
InstancedRenderer
  └─ EnhancedRenderer
       ├─ 建物複合形状
       ├─ 道路ディテール
       ├─ 駐車区画
       ├─ 街灯/樹木
       ├─ 歩行者部品
       ├─ 車両部品
       └─ バス停シェルター
```

既存の `Inspector` は `InstancedRenderer` の建物/市民/車両の代表MeshをRaycast対象として利用するため、EnhancedRendererでは代表Meshを維持して互換性を保つ。

## 8. 都市生成設計

### 8.1 都市化度

FBMノイズと都市中心からの距離を組み合わせて都市化度を算出する。

市街地目標比率に合わせて64×64サンプルから閾値を校正する。

### 8.2 道路

市街地は密格子、郊外は疎格子を生成する。道路は格子線方向に接続し、必要に応じて孤立連結成分を補修する。

### 8.3 建物用途

主用途は `POICategory` により定義する。

- Home
- Work
- Food
- Retail
- Leisure

### 8.4 建築アーキタイプ

用途と見た目を1対1にしない。用途・都市化度・階数・乱数から建築アーキタイプを選択する。

```text
DetachedHouse
TownHouse
LowRiseApartment
MidRiseApartment
ResidentialTower
SmallOffice
OfficeSlab
OfficeTower
SmallShop
RetailBox
CommercialBlock
MixedUse
LeisureHall
```

これにより、同じHomeでも郊外戸建から都心住宅タワーまで変化させる。

### 8.5 建物外観パラメータ

`Building` はシミュレーション用途に加え、描画専用の以下の情報を保持する。

- archetype
- roofType
- palette
- styleSeed
- rotation
- urbanity

`styleSeed` は建物ごとの外観差を決めるために利用し、シミュレーションロジックには依存させない。

### 8.6 MixedUse

`MixedUse` は単一の新POIカテゴリではなく、1つの建物に複数POIを登録する建築アーキタイプとして扱う。

例:

```text
上層: Home / Work
低層: Retail / Food
```

## 9. 主要データモデル

### Agent

位置、速度、向き、欲求、資産、年齢、職業、勤務時間、外向性、行動状態、自宅/職場/目的地、徒歩経路、自動車、バス情報をSoAで保持する。

### Vehicle

自家用車、バス、トラックを同一Storeで管理する。IDMパラメータ、道路Edge、経路、駐車情報を保持する。

### POI

category / 座標 / priceTier / capacity / occupancy / buildingId / stock / maxStock を保持する。

### Building

位置、寸法、階数、主用途に加え、アーキタイプと外観バリエーションを保持する。

## 12. 交通・移動

- 遠距離判定: 180m以上
- 90m以上かつ energy < 0.4 も遠距離
- 優先: 自家用車 -> バス -> 徒歩
- バス: 出発地/目的地350m以内の停留所かつ共通1路線
- 自家用車: 徒歩 -> 駐車車両 -> 道路走行 -> 目的地駐車場 -> 徒歩

A*は車両では時間コスト、徒歩では距離コストを使用する。

## 13. レンダリング設計

### 13.1 基本方針

高ポリモデルやテクスチャ大量利用ではなく、少数の基本GeometryをInstancedMeshで再利用し、シルエットと部品構成で識別性を上げる。

### 13.2 建物

既存の1Box建物は透明なRaycast用hit proxyとして残し、可視建物は拡張側の複合形状で再構成する。

- 色付き外装Shell
- Tower / Upper volume
- ガラス面パネル
- Gable/Hip風屋根
- 屋上機械設備
- 商業建物の庇

都市化度とアーキタイプにより、戸建・集合住宅・タワー・商業建物等の形状分布を変える。

### 13.3 車両

既存の車体代表Meshに加え、動的Instancingで以下を同期する。

- Cabin / Window volume
- 前後車輪相当部品
- Head lamp
- Tail lamp

自家用車はIDから4系統のシルエット差を生成する。バス/トラックは専用寸法を使用する。

### 13.4 歩行者

既存CapsuleをRaycast代表として維持し、上へ以下を追加する。

- Torso
- Head
- Left/Right Leg

移動時はシミュレーション時刻と歩行速度から脚振り位相を算出する。

### 13.5 道路・街路

静的Instancingで以下を追加する。

- 縁石
- 幹線道路中央分離帯
- Highwayガードレール
- 駐車区画線
- 街灯
- 樹木
- 一部バス停シェルター/ベンチ

### 13.6 昼夜

`SimulationClock.dayPhase` から太陽高度を算出し、以下を時間帯に連動させる。

- DirectionalLight位置/強度/色
- HemisphereLight強度
- Scene背景色
- Fog色

## 14. 性能方針

維持する原則:

- SoA / TypedArray
- GPU Instancing
- 代表Geometryの再利用
- 静的ディテールは起動時生成
- 動的ディテールはAgent/Vehicle Store走査時に同期
- 1オブジェクト=多数の個別THREE.Mesh は避ける

駐車区画線は描画インスタンス数の暴走を防ぐため上限を設ける。

将来的な大規模化ではSimulation LOD、描画LOD、チャンク、Worker、経路探索キャッシュを導入する。

## 15. 現行制約

- 建物外観はプリミティブ複合形状であり、建物内部は未実装。
- 窓は個別窓ではなく大きなガラス面パネル表現。
- 建物アーキタイプは都市計画ゾーニングではなく、用途/都市化度/乱数に基づく。
- 車両の4系統差は描画専用で、走行性能差には接続していない。
- 歩行者アニメーションは簡易脚振りで、ボーンアニメーションではない。
- 街灯の発光強度は現状固定で、夜間だけの点灯制御は今後拡張可能。
- Health / Education の主要機能接続は未実装。

---

## 16. 拡張原則

見た目のバリエーションはシミュレーション状態と分離し、必要な場合のみStore/Buildingへ外観Seedを保持する。

新しい建物形状は原則として `BuildingArchetype` の追加と `EnhancedRenderer` の組み合わせで実装する。

大規模化時には、アーキタイプ単位のGeometry統合、距離LOD、街区単位の表示/非表示を追加する。
