# City-Sim 都市設定ファイル仕様

## 1. 目的

都市生成条件と初期人口をソースコードから分離し、コード変更なしで都市規模・市街地率・Seed・人口・Store容量を変更できるようにする。

設定ファイルは `public/config/city.json` とし、ブラウザ起動時に `/config/city.json` から読み込む。

## 2. 設定項目

| 項目 | 型 | 説明 |
|---|---|---|
| `seed` | number または `"random"` | 都市生成Seed。数値なら固定、`random`なら起動ごとに32bit Seedを生成する。 |
| `areaKm2` | number | 都市全体の面積。正方形都市の一辺は `sqrt(areaKm2 * 1,000,000)` m。 |
| `urbanRatioTarget` | number | 市街地の目標比率。0～1。 |
| `blockSize` | number | 基準街区サイズ[m]。 |
| `population` | integer | 初期市民生成要求数。 |
| `agentCapacity` | integer | AgentStore最大容量。`population`以上とする。 |
| `vehicleCapacity` | integer | VehicleStore最大容量。 |

## 3. 現在の試験設定

```json
{
  "seed": "random",
  "areaKm2": 100,
  "urbanRatioTarget": 0.4,
  "blockSize": 90,
  "population": 50000,
  "agentCapacity": 60000,
  "vehicleCapacity": 30000
}
```

100km²は一辺10km、目標市街地面積は40km²となる。

人口50,000人は、旧設定の10km²・4,000人から都市規模を拡大した試験値である。旧設定の市街地面積約3.33km²に対する人口密度を概ね維持すると約48,000人となるため、端数を丸めて50,000人とした。

## 4. Seed運用

### 毎回異なる都市

```json
"seed": "random"
```

ブラウザの `crypto.getRandomValues()` を優先してSeedを生成する。生成した実SeedはConsoleとHUDへ表示する。

気に入った都市を再現したい場合は、HUDに表示されたSeedを設定ファイルへコピーする。

### 固定都市

```json
"seed": 123456789
```

同じSeed、面積、市街地率、blockSizeで都市地形・道路・建物生成を再現することを意図する。

ただし現行実装ではAgentStore、VehicleStore、滞在時間等の一部に `Math.random()` が残っているため、シミュレーション全体の完全決定論は保証しない。

## 5. 起動処理

`src/config/CityConfigLoader.ts` がJSONを読み込み、値域検証を行う。

処理順:

```text
/config/city.json
  -> loadCityConfig()
  -> resolveCitySeed()
  -> areaKm2 から sizeMeters 算出
  -> World生成
  -> populate(population)
  -> Renderer / UI生成
```

設定ファイルの取得失敗または不正値がある場合は、誤った条件で都市を生成せず起動エラーとして画面に表示する。

## 6. 大規模都市での注意

100km²・50,000人は現行アーキテクチャに対する負荷試験を兼ねる設定である。

特に負荷が増加する箇所:

- `World.step()` のAgent全走査
- Utility AI
- 徒歩/車両A*
- TrafficSystemのEdge occupants再構築・sort
- Agent/Vehicle描画同期
- 100km²分の道路・建物・街路設備InstancedMesh

FPSやシミュレーション処理が不足する場合は、単純に人口を戻すだけではなくSimulation LOD、チャンク分割、遠方Agentの統計化、A*キャッシュ/Worker化を優先して検討する。
