# City-Sim 都市設定ファイル仕様

## 1. 目的

`public/config/city.json` の入力値を定義する。最終的な正は現行コード。文書同期時点: `v1.0.12`。

## 2. トップレベル

| 項目 | 現行生値 | 説明 |
|---|---:|---|
| `seed` | `random` | 都市Seed |
| `areaKm2` | 100 | 都市面積[km²] |
| `urbanRatioTarget` | 0.4 | 市街地目標比率 |
| `blockSize` | 90 | 基準街区[m] |
| `population` | 50000 | 初期人口 |
| `agentCapacity` | 120000 | AgentStore容量 |
| `vehicleCapacity` | 30000 | VehicleStore容量 |
| `planning` | object | 都市/鉄道計画 |
| `power` | object | 電力系統設定 |

## 3. planning

`subCenters=3`, `arterialSpacing=900`, `collectorSpacing=360`, `industrialRatio=0.08`, `parkRatio=0.055`, `railEnabled=true`, `railTrunkLines=3`, `railStationSpacing=525`, `railInfluenceRadius=900`, `railSubCenterSpurs=true`。

`railStationSpacing`は固定実距離ではなく基準値。runtimeで郊外ほど最大約2倍になる。`parkRatio`は初期計画値で、最終公園量とは1対1対応しない。

### 4.1 値域

`CityConfigLoader`は主要power値を検証する。更新周期0.25..3600秒、発電所/接続数は所定整数範囲、容量は正値、予備率0..2、blackout供給率0..0.5、非常電源比率0..1、周波数45..65 Hz、系統電圧1..500 kV、需要家電圧100..1000 V、droop/電圧降下係数0..所定上限、位相偏移0..45°、R/X 0..10 Ω/km。

`demandUpdateIntervalSec`は現行`PowerConfig`の静的interface/Loader個別validatorには含まれず、P12 tuningがruntime object上の値を読み、未指定時は`max(updateIntervalSec, 15)`へfallbackする。この項目を正式schemaへ昇格する場合は`PowerTypes.ts`と`CityConfigLoader.ts`を同期すること。

## 5. Seed

`random`は乱数seed、数値指定は静的都市生成の再現用。動的simulation全体の完全決定論は保証しない。

## 6. 設定変更時

設定変更時は `CityConfigLoader.ts`、`public/config/city.json`、本書、`現行仕様書.md`、必要に応じて`電力システム仕様.md`と詳細設計を同期する。
