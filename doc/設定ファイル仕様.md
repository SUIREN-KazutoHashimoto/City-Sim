# City-Sim 都市設定ファイル仕様

## 1. 目的

`public/config/city.json` の入力値を定義する。最終的な正は現行コード。文書同期時点: `v1.0.15`。

## 2. トップレベル

| 項目 | 現行生値 | 説明 |
|---|---:|---|
| `seed` | `random` | 都市Seed |
| `areaKm2` | 100 | 都市面積[km²] |
| `urbanRatioTarget` | 0.4 | 市街地目標比率 |
| `blockSize` | 90 | 基準街区[m] |
| `population` | 50000 | 初期人口 |
| `agentCapacity` | 120000 | AgentStore容量 |
| `vehicleCapacity` | 30000 | VehicleStore容量 |
| `planning` | object | 都市/鉄道計画 |
| `power` | object | 電力系統設定 |

## 3. planning

`subCenters=3`, `arterialSpacing=900`, `collectorSpacing=360`, `industrialRatio=0.08`, `parkRatio=0.055`, `railEnabled=true`, `railTrunkLines=3`, `railStationSpacing=525`, `railInfluenceRadius=900`, `railSubCenterSpurs=true`。

`railStationSpacing`は固定実距離ではなく基準値。runtimeで郊外ほど最大約2倍になる。`parkRatio`は初期計画値で、最終公園量とは1対1対応しない。

## 4. power

### 4.1 基本系統

| 項目 | 現行値 | 説明 |
|---|---:|---|
| `enabled` | true | 電力システム有効化 |
| `updateIntervalSec` | 5 | 配電更新周期[simulation sec] |
| `demandUpdateIntervalSec` | 15 | 需要再計算周期[simulation sec] |
| `thermalPlantCount` | 2 | 火力発電所数 |
| `thermalPlantCapacityMw` | 350 | 火力1基容量[MW] |
| `solarPlantCount` | 3 | 太陽光発電所数 |
| `solarPlantCapacityMw` | 90 | 太陽光1基容量[MW] |
| `externalConnectionCount` | 2 | 外部系統接続数 |
| `externalGridCapacityMw` | 600 | 外部接続1点容量[MW] |
| `substationSpacingMeters` | 1800 | 変電所配置基準間隔[m] |
| `substationCapacityMw` | 75 | 変電所容量[MW] |
| `substationServiceRadiusMeters` | 2600 | 配電サービス半径[m] |
| `lineCapacityHighwayMw` | 260 | Highway地下線容量[MW] |
| `lineCapacityArterialMw` | 180 | Arterial地下線容量[MW] |
| `lineCapacityCollectorMw` | 110 | Collector地下線容量[MW] |
| `lineCapacityLocalMw` | 55 | Local地下線容量[MW] |
| `lineCapacityPathMw` | 12 | Path地下線容量[MW] |
| `tightReserveMarginRatio` | 0.15 | 逼迫判定の予備率 |
| `blackoutSupplyRatio` | 0.05 | blackout判定供給率 |
| `criticalEmergencySupplyRatio` | 0.35 | Critical非常電源比率 |

### 4.2 電力品質

| 項目 | 現行値 | 説明 |
|---|---:|---|
| `nominalFrequencyHz` | 50 | 公称周波数[Hz] |
| `nominalGridVoltageKv` | 22 | 系統公称電圧[kV] |
| `serviceVoltageV` | 400 | 需要家基準電圧[V] |
| `frequencyDroopRatio` | 0.04 | 周波数droop係数 |
| `voltageLoadDropPu` | 0.025 | 負荷由来電圧降下係数 |
| `reactiveVoltageDropPu` | 0.018 | 無効電力由来電圧降下係数 |
| `phaseImbalanceVoltageDropPu` | 0.035 | 相不平衡由来電圧降下係数 |
| `maxZonePhaseShiftDeg` | 6 | Zone最大位相偏移[deg] |
| `lineResistanceOhmPerKm` | 0.18 | 線路抵抗[Ω/km] |
| `lineReactanceOhmPerKm` | 0.11 | 線路リアクタンス[Ω/km] |

### 4.3 ライフライン人員

| 項目 | 現行値 | 説明 |
|---|---:|---|
| `lifelineRosterReliefRatio` | 1.15 | 3交代の必要人数に上乗せする休日/交代要員比率 |
| `thermalPlantStaffPer100Mw` | 4.5 | 火力100 MWあたりの同時勤務目標人数 |
| `solarPlantStaffPer100Mw` | 1.5 | 太陽光100 MWあたりの同時勤務目標人数 |

発電所は3交代勤務を前提とし、ロスター目標は概ね `同時勤務人数 × 3 × lifelineRosterReliefRatio`。通常職場の50%保証より優先し、ライフライン職場はロスター100%を割当目標とする。

### 4.4 火力燃料・輸送

| 項目 | 現行値 | 説明 |
|---|---:|---|
| `thermalFuelUnitsPerMwh` | 0.18 | 発電1 MWhあたりの抽象燃料消費単位 |
| `thermalFuelStorageHours` | 96 | 最大出力換算の貯蔵時間[h] |
| `thermalFuelReorderHours` | 60 | 補給要求開始残時間[h] |
| `thermalFuelEmergencyHours` | 18 | 緊急補給扱い開始残時間[h] |
| `thermalFuelTruckCapacityUnits` | 180 | 燃料輸送車1台の積載量 |
| `thermalFuelFleetSize` | 10 | 都市全体の燃料輸送車上限 |
| `thermalFuelInternalReserveRatio` | 0.25 | 市内raw-factoryに残す最低出力在庫比率 |

火力燃料は発電実績に応じて消費する。`stock + 輸送中` が補給点を下回ると発注し、市内 `raw-factory` の余剰在庫を優先する。余剰が不足する場合は外部ゲートから輸入する。いずれも実際のTruckが道路を走行して発電所へ到着・荷下ろししてから在庫へ加算される。

## 5. 値域検証

`CityConfigLoader` はpower値を正式に検証する。主な範囲は以下。

- `updateIntervalSec`: 0.25..3600 sec
- `demandUpdateIntervalSec`: `updateIntervalSec`..3600 sec
- 発電所/接続/燃料車数: 所定整数範囲
- 発電/変電/線路容量: 正値
- 予備率: 0..2
- blackout供給率: 0..0.5
- 非常電源比率: 0..1
- 周波数: 45..65 Hz
- 系統電圧: 1..500 kV
- 需要家電圧: 100..1000 V
- lifeline roster relief: 1..2.5
- 燃料貯蔵時間: 1..720 h
- 燃料reorder時間: 0..storage hours
- 燃料emergency時間: 0..reorder hours
- internal reserve ratio: 0..0.95

`demandUpdateIntervalSec` はv1.0.15で正式な `PowerConfig` 項目へ昇格し、Loader個別validatorの対象になった。

## 6. Seed

`random`は乱数seed、数値指定は静的都市生成の再現用。動的simulation全体の完全決定論は保証しない。

## 7. 設定変更時

設定変更時は `CityConfigLoader.ts`、`public/config/city.json`、本書、`現行仕様書.md`、必要に応じて`電力システム仕様.md`と詳細設計を同期する。
