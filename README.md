# City-Sim

TypeScript / three.js / Vite で動作するブラウザ向けリアルタイム都市シミュレーションです。現行標準構成は 100 km²・5万人規模で、市民、徒歩、自家用車、バス、物流、在来鉄道、外部接続高速鉄道を同一の都市時間上で扱います。

## 現行標準構成

`public/config/city.json` の通常起動設定:

- 都市面積: 100 km²
- 人口: 50,000
- Agent capacity: 60,000
- Vehicle capacity: 30,000
- 市街地目標比率: 40%
- 幹線鉄道: 3路線
- `railStationSpacing` 設定値: 525 m
- 駅影響半径: 900 m

注意: `RailPlanningEnhancements` には既定駅間隔を1.5倍する処理がありますが、通常起動では `city.json` の明示値 525 m が優先されます。したがって**現行コードの通常起動での実効駅間隔は525 m**です。

## 主な現行機能

- CBD・副都心・用途地区・道路階層・Block/Parcel・建物/POIの手続き生成
- Utility AIによる市民生活と、徒歩・自家用車・バス・鉄道の実移動
- IDM系道路交通、信号、横断歩道、連続Bezier旋回軌跡
- 店舗在庫と外部ゲートからの物流配送
- 道路A*経路を基準とする在来鉄道、幹線3路線と副都心支線
- 普通/快速/特急、閉塞、信号、渡線、15秒グリッドのダイヤ
- 終電後/出庫時の回送、終端駅、車両基地
- 実列車への乗降、ホーム待機、駅内3D移動、最大1回乗換
- 270 m以上の終端ホーム、緩曲線に追従するホーム、島式待避線10.4 mオフセット
- 天井吊り下げ発車案内板、ベンチ、自販機、蛍光灯、実照明、列車前照灯
- 駅前の低層Food/Retail/Leisure系商業化と、線路実占有範囲だけのクリアランス
- 外部接続高速鉄道とInspector追跡
- 描画フィルター（線路・駅設備と列車を独立制御）
- 移動/リサイズ可能な統計HUD、時間・速度、描画フィルター、Performance、追跡情報ウィンドウ
- SharedArrayBuffer / Worker / LOD / GPU Instancing / A* cacheによる大規模化対応

## 開発

```bash
npm install
npm run dev
```

ビルド:

```bash
npm run build
```

`npm run build` はアプリ本体の生成後、`LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.txt` を `dist/` 直下へ自動コピーします。配布時はこれらの法的ファイルを成果物から除外しないでください。

プレビュー:

```bash
npm run preview
```
