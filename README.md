# City-Sim

TypeScript / three.js / Vite で動作するブラウザ向けリアルタイム都市シミュレーションです。現行標準構成は 100 km²・5万人規模で、市民生活、徒歩、自家用車、短距離バス、タクシー、産業物流、在来鉄道、外部接続高速鉄道を同一の都市時間上で扱います。

## 現行標準構成

`public/config/city.json` の通常起動設定:

- 都市面積: 100 km²
- 人口: 50,000
- Agent capacity: 60,000
- Vehicle capacity: 30,000
- 市街地目標比率: 40%
- 基準街区: 90 m
- 幹線鉄道: 3路線
- `railStationSpacing` 基準値: 525 m
- 駅影響半径: 900 m

`railStationSpacing=525` は駅配置の**基準値**です。`RailRuralStationSpacing` によりCBD付近はほぼ基準値、外縁ほど最大約2倍まで駅間隔が広がります。

`planning.parkRatio=0.055` は初期都市計画の入力値で、最終公園数そのものではありません。現行生成では最終段で周辺高さ帯に応じて公園を再整理します。

## 主な現行機能

### 都市・土地利用

- CBD、副都心、用途地区、道路階層、Block/Parcel、建物/POIの手続き生成
- 高密度ほど多車線になる Arterial / Collector と、密度別の Local 道路間引き
- 高層以上区画 約2%、中層 約1%、低層 約5%を目安上限とする公園整理
- 駅周辺の最終建築禁止クリアランスと線路包絡クリアランス
- 郊外の大型農場、工場、タクシー/バス/物流営業所
- 車道クリアランス内の街路樹・森林樹木の描画除外

### 市民・道路交通

- Utility AIによる勤務、食事、買物、娯楽、帰宅
- 徒歩、自家用車、バス、タクシー、鉄道の実移動
- 多車線道路、車線変更、右左折レーン、信号、横断歩道、IDM系追従
- 交差点内で進入車線から退出車線へ連続する右左折表示軌道
- 歩行者信号が赤の場合、経路を捨てず横断歩道入口で青まで待機

### バス・タクシー・物流

- 一般バス路線は実道路走行距離ベースで**1路線5 km以下**
- 旧長距離6系統を短区間へ分割し、標準10 km都市では概ね24路線前後以上
- 1路線あたり3～4台、駅フィーダーも5 km以下・3～4台
- バスはバス営業所、タクシーはタクシー営業所、トラックは物流営業所から運用
- タクシーは住民・来訪者が距離、時間帯、資産等に応じて選択
- 農場/原料工場 → 加工工場 → 組立工場 → Retail/Food または外部輸出の3段階物流

### 農場・職場

- 農場は複数街区規模の畑 + 事務所 + 倉庫
- 農場内を一般道路が横切らないよう生成
- 農場の100%稼働時生産能力は畑面積で決定
- 実生産量は `基礎生産量 × 出勤人数 / 定員`
- Inspectorに職場種別、出勤人数、在籍人数、定員、稼働/生産効率を表示

### 鉄道・描画

- 道路A*経路を基準とする在来鉄道、幹線3路線と副都心支線
- 普通/快速/特急、閉塞、信号、渡線、15秒グリッドのダイヤ
- 終電後/出庫時の回送、終端駅、車両基地
- 実列車への乗降、ホーム待機、駅内3D移動、最大1回乗換
- 天井吊り下げ発車案内板、ベンチ、自販機、蛍光灯、実照明、列車前照灯
- 外部接続高速鉄道とInspector追跡
- SharedArrayBuffer / Worker / LOD / GPU Instancing / A* cacheによる大規模化対応

## 開発

```bash
npm install
npm run dev
```

ビルド:

```bash
npm run build
```

`npm run build` は `tsc` と Vite build の後、`LICENSE`、`NOTICE`、`THIRD_PARTY_NOTICES.txt` を `dist/` 直下へコピーします。配布時はこれらの法的ファイルを成果物から除外しないでください。

プレビュー:

```bash
npm run preview
```
